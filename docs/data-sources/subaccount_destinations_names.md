# btp_subaccount_destinations_names (Data Source)

Gets a list of all subaccount destination names.
__Tip:__
You must have the appropriate connectivity and destination permissions, such as:

Subaccount Administrator
Destination Administrator
Destination Viewer
Connectivity and Destination Administrator

## Example Usage

```terraform
# Read all destination for a given subaccount
data "btp_subaccount_destinations_names" "dest_by_subaccount" {
  subaccount_id = "6aa64c2f-38c1-49a9-b2e8-cf9fea769b7f"
}


# Read all destination for a given subaccount and service instance
data "btp_subaccount_destinations_names" "dest_by_subaccount_and_service_instance" {
  subaccount_id       = "6aa64c2f-38c1-49a9-b2e8-cf9fea769b7f"
  service_instance_id = "5aa54c2f-47a1-49a9-b2e8-cf9fea769b7f"
}

# Read all destination for a given subaccount, service instance and extension landscape
data "btp_subaccount_destinations_names" "dest_by_subaccount_and_service_instance_on_cf_ext" {
  subaccount_id       = "6aa64c2f-38c1-49a9-b2e8-cf9fea769b7f"
  service_instance_id = "5aa54c2f-47a1-49a9-b2e8-cf9fea769b7f"
  extension_landscape = "cf-eu12-001"
}
```

## Schema

### Required

- `subaccount_id` (String) The ID of the subaccount.

### Optional

- `extension_landscape` (String) The label of the extension landscape of the targeted service instance. Specify this parameter only when the service instance resides on a Cloud Foundry extension landscape. You can obtain the landscape label from the Cloud Foundry environment instance information of the subaccount, for example via the commands for the 'accounts/environment-instance' object.
- `service_instance_id` (String) The service instance that becomes part of the path used to access the destination of the subaccount.

## Destinations assigned to Service Instances on Cloud Foundry Extension Landscapes

In case you want to read destinations assigned to service instances on a Cloud Foundry **extension landscape**, you must provide the attribute `extension_landscape`.

You can retrieve the value of the extension landscape e.g., via the attribute `landscape_label` of the resource `btp_subaccount_environment_instance` or via the same attribute of the data source `btp_subaccount_environment_instance`.
